## Build notes (from QA of the boards)
- Board text such as prices, names and addresses is sample content. Fees come from settings, products from the catalogue.
- Owl faces differ slightly between boards; always use the asset sheet.
- Book centre button: use the calendar icon + "Book" label (from board 00b).
- Payments board shows "Due" and "Paid" tabs with a due hero card; keep both.
- Real product photography replaces 3D bottles in the live shop (brand guide §6).
