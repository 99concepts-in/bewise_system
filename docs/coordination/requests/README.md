# Cross-chat requests

One new file per request: `<YYYYMMDD>-<from>-to-<to>-<slug>.md` (e.g. `20261121-client-to-manager-product-badges.md`).
Never edit a shared list. The receiving chat replies inside the same file and updates `Status:`
(OPEN → ACCEPTED → DONE, or DECLINED with a reason). Template and rules: `docs/04-COORDINATION-PROTOCOL.md` §5.

Chat tags: `hub`, `consultant`, `client`, `manager`, `owner`.
